Code Availability
=================

Code used to reproduce the validation analyses, preprocessing/evaluation scripts, harmonization documentation, the frozen 15-predictor GBC model artefact with SHA-256 checksum, selected hyperparameter grids, aggregate result tables, selected figure-generation scripts, exact package versions and a Dockerfile for reproducing the analysis environment are publicly available at:

https://github.com/hugogo23/survey-lcp-external-validation

The repository will be archived at Zenodo before resubmission (DOI: DOIXXX). Code is released under the MIT license. Raw CHARLS and CFPS individual-level data are not redistributed because access is governed by the original cohort data-use agreements. Data-access instructions are provided in `data/README.md`.
